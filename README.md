# درسّي — تطبيق موبايل لإدارة الدروس الخصوصية

تطبيق ويب عربي RTL بنمط Mobile‑First لإدارة الطلاب، الجلسات، المدفوعات والديون. يعمل محلياً، ويمكن تثبيته على الهاتف كتطبيق PWA عند تشغيله من استضافة HTTPS أو خادم محلي.

## أهم المزايا

- لوحة تحكم مالية: المتوقع، المحصل، المتبقي، الساعات والجلسات.
- تسجيل جلسة رياضيات / فيزياء / كيمياء مع حساب تلقائي.
- حالات دفع: كامل، غير مدفوع، دفعة جزئية.
- تسديد دين قديم جزئياً أو بالكامل مع سجل دفعات.
- إدارة طلاب كاملة:
  - إضافة طالب جديد.
  - تعديل الاسم والعنوان والسعر.
  - اختيار التسعير بالساعة أو مبلغ ثابت للجلسة.
  - أرشفة الطالب مع الاحتفاظ بكل سجله.
  - إعادة تفعيل الطالب لاحقاً.
  - حذف نهائي فقط إذا لم يكن لديه جلسات، لحماية السجل المالي.
- أسعار الجلسات القديمة تبقى محفوظة حتى بعد تغيير سعر الطالب.
- بحث في الطلاب وفلترة حسب الحالي/المؤرشف.
- زر سريع لإضافة جلسة مباشرة لطالب معين.
- سجل جلسات ببطاقات مخصصة للموبايل وجدول لسطح المكتب.
- فلاتر حسب الطالب، المادة، حالة الدفع والشهر.
- تصدير CSV.
- نسخة احتياطية JSON تشمل الطلاب والجلسات، واستعادتها لاحقاً.
- حفظ محلي تلقائي عبر `localStorage`.
- PWA مع Manifest + Service Worker + أيقونات تطبيق.
- تصميم RTL متجاوب وشريط تنقل سفلي للموبايل.

## التشغيل السريع

### 1) بدون تثبيت
افتح الملف:

`tutoring-dashboard-standalone.html`

سيعمل مباشرة في المتصفح، مع حفظ البيانات على نفس المتصفح والجهاز.

### 2) تشغيل المشروع الكامل
من داخل مجلد المشروع:

```bash
python -m http.server 8080
```

ثم افتح:

`http://localhost:8080`

## تثبيت التطبيق على الهاتف

لأفضل تجربة PWA، ارفع مجلد المشروع على استضافة HTTPS مثل Netlify / Vercel / GitHub Pages أو أي استضافة ويب عادية.

- Android/Chrome: سيظهر خيار تثبيت التطبيق عندما يسمح المتصفح بذلك، أو من قائمة المتصفح > تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
- iPhone/Safari: مشاركة > إضافة إلى الشاشة الرئيسية.

> ملاحظة: Service Worker لا يعمل عند فتح الملف بصيغة `file://` مباشرة. النسخة المستقلة تبقى قابلة للاستخدام، لكن التثبيت كتطبيق يحتاج HTTP/HTTPS.

## التخزين والخصوصية

البيانات تحفظ افتراضياً على الجهاز نفسه داخل المتصفح. لا تُرسل إلى خادم خارجي. استخدم زر النسخة الاحتياطية بشكل دوري خصوصاً قبل حذف بيانات المتصفح أو تبديل الهاتف.

## ملفات المشروع

- `index.html` — هيكل الواجهة.
- `styles.css` — التصميم والاستجابة للموبايل.
- `app.js` — منطق الطلاب والجلسات والمدفوعات.
- `manifest.webmanifest` — إعداد تثبيت PWA.
- `service-worker.js` — العمل Offline وتخزين ملفات الواجهة.
- `icons/` — أيقونات التطبيق.
- `tutoring-dashboard-standalone.html` — نسخة HTML واحدة للاستخدام المباشر.
